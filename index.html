Abstract

Saudi Arabia is preparing to host millions of visitors at the Hajj, Riyadh Season, the Asian Cup 2027, and Expo 2030, while manual CCTV monitoring is limited by human attention and reaction time. CrowdSense is a real-time crowd monitoring system that estimates crowd counts and density maps from camera footage, visualizes them on a web dashboard, and raises threshold-based alerts. It builds on the Multifaceted Attention Network (MAN), which combines global transformer attention with learnable region attention to cope with the large scale variation in crowd scenes. Because public benchmarks contain few scenes with traditional Arab attire such as thobes, shemaghs, hijabs, and niqabs, we fine-tuned the model on a custom Arab-context set of 400 annotated images from Hajj gatherings and local festivals, augmented to 2,000. Adaptation reduced counting MAE on Arab-context scenes from 87.3 to 62.8 (28.1%). In system testing, the deployed pipeline reached 87% count accuracy against manual counts, triggered alerts in 2.1 s, and processed a single stream in 0.8 s; with ten concurrent streams, processing time exceeded the 2 s target.

  • Arab-context adaptation

    A culturally specific annotated crowd set and a fine-tuned MAN model that lowers counting error on Saudi scenes by 28.1% MAE.

  • An end-to-end system

    A FastAPI inference service, an image-analysis page, and a monitoring dashboard with normal, density, and overlay views.

  • Tested against requirements

    A system test plan and report covering accuracy, latency, alerting, and load, with failures and open issues stated.

Method

Density regression with multifaceted attention

A VGG-19 backbone extracts features at 1/32 resolution. A four-layer transformer encoder mixes a small share of global attention with learnable region attention, which decides for every location how large a neighbourhood to look at, so large nearby heads and tiny distant ones are both handled. A convolutional head turns the result into a density map; its sum is the count.

Components

  • Learnable region attention

    Learns a per-location attention region, so the receptive field adapts to the scale of the heads around it.

  • Global attention

    Standard transformer attention over the whole frame, weighted 0.1 and added to the local term.

  • Local attention regularization

    Training loss that encourages similar attention for objects of similar real size.

  • Instance attention

    Training loss that down-weights noisy head annotations.

  • Serving

    FastAPI resizes each upload so its short side is 512 px, runs the model on GPU when available, and returns the count with a JET heatmap blended 60:40 over the image.

System

Four layers: cameras or recorded video feed the fine-tuned model, whose outputs pass through a database and stream processor to the web dashboard.

Across scenes

Reading these results

  • The Arab-context set is small and was collected and annotated by the team; other Saudi venues, camera heights, and lighting conditions were not measured.
  • The benchmark table reproduces published MAN numbers for context; this project does not re-evaluate MAN on those datasets.
  • Latency and load figures come from the team's test environment. Full-scale testing at Hajj-like volumes was not possible, and performance degraded beyond 10 streams or 100 concurrent users.
  • In the dashboard demo, summary statistics, alerts, and flow rate are simulated; only the video views come from the model.

Code

Run the inference API

With Python 3.9 or newer. Place a checkpoint at backend/weights/model.pth or set CROWDSENSE_WEIGHTS; weights are not stored in the repository. Then open frontend.html and drop in a crowd image. 

git clone https://github.com/safwanx/CrowdSense.git
cd CrowdSense
pip install -r backend/requirements.txt
cd backend
python -m uvicorn main:app
curl -F "file=@crowd.jpg" http://localhost:8000/predict/
# {"count": 84, "heatmap_url": "/static/heatmap_84.jpg", "status": "success"}
